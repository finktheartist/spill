# Contributing

Start with the [code map](docs/architecture.md) and [development guide](docs/development.md).

Keep changes focused, describe the behavior they change, and include the checks you ran. Tests belong beside the affected module. Preserve third-party attribution and keep credentials, personal photos, and private exports out of commits.

For rendering or instruction changes, include a concise description of the browser or physical checks you performed. Automated tests alone do not establish visual or physical correctness.
